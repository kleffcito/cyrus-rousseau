ROUSSEAU CYRUS - BITACORA MANGA

CONTENIDO
- index.html: lector interactivo
- images/: portadas y páginas actuales

PROBAR EN TU ORDENADOR
Abre index.html en un navegador. Los controles de página y el teclado funcionan sin instalar nada.

PUBLICAR GRATIS EN GITHUB PAGES
1. Crea un repositorio en GitHub (por ejemplo: cyrus-manga).
2. Sube index.html y la carpeta images completa a la raíz del repositorio.
3. En el repositorio, entra en Settings > Pages.
4. En Build and deployment, elige Deploy from a branch.
5. Selecciona la rama main y la carpeta / (root), guarda y espera a que GitHub publique la web.

AÑADIR PÁGINAS
1. Copia la nueva imagen a images/ (por ejemplo pagina-06.png).
2. Abre index.html y añade un objeto a la lista `pages` en el orden deseado.
3. Guarda y vuelve a subir ambos archivos a GitHub.

NOTAS
- El lector admite clic, flechas del teclado y gestos horizontales en móviles.
- Las imágenes incluidas son las páginas disponibles en esta conversación. Puedes reemplazarlas conservando sus nombres o actualizar las rutas en index.html.
